SKIPPED (with reasons - accepted decision)
------------------------------------------------------------

  bip39-generator        - needs the full 2048-word BIP-39 wordlist.
  mac-address-lookup     - needs a MAC vendor database (would be large static blob).
  pdf-signature-checker  - PDF parsing/signature validation is impractical client-side.
  wifi-qr-code-generator - QR code generation already covered by qr-code-generator.

PER-BATCH STANDARD PROCESS (follow for every batch)
------------------------------------------------------------
  1. Generate:        node troolify-gen/gen-tools-batchN.js
  2. Static verify:   node "C:\Users\SKYLIMIT OFFICE\AppData\Local\Temp\opencode\verify-pages.js" <page...>
                      PLUS check-scripts.js on every page (validates ALL inline
                      scripts, not just the first) - base64 bug proved the first
                      script passes while a later one has a syntax error.
  3. Browser test on http://127.0.0.1:8123 for interactivity (each tool's
     Go/Sample path, async via poll() for crypto.subtle / FileReader / MediaRecorder).
  4. HTML-escape check: desc / metaDesc / hero <p> must NOT contain literal
     <script>, <style>, etc. (unescaped <script> in an element context mangles
     the whole page DOM - batch 6 base64-file-converter hit this).
  5. Conclusion links: use same-folder pages or ../folder/page.html (cross-
     folder bare links 404 - batch 6 hit this on benchmark-builder).
  6. Pipeline:  npm run minify   -->   node troolify-gen/update-site-meta.js
  7. Commit + push to main.

KNOWN NITS / FOLLOW-UPS
------------------------------------------------------------
  - tools/coding/html-minifier.html FAQ JSON-LD text contains a literal
    "<script>" inside application/ld+json. It is BENIGN for the parser (it is
    inside a script element body) but should ideally be escaped for tidiness.
  - benchmark-builder default sample (100000 iters x 3 warmups) takes ~29s in
    the throttled test browser; in normal desktop browsers it is milliseconds.
    Consider lowering the sample to 10000 if real users report slow runs.
  - regex-memo saves to localStorage key "troolify.regexMemo" - fine, just noted.
  - meta-tag-generator unshifts the OG/Twitter input fields via DOM insertion
    and its Clear handler contains a dead forEach(function(){}) - harmless.
  - otp-code-generator-and-validator needs a secure context (https or
    localhost) for crypto.subtle; secure-context fallback message is in place.
