SSH Key Generator: Make Ed25519 and RSA Keys in the Browser

SSH keys are the standard way to log in to servers and push to repositories without a password. This SSH key generator creates Ed25519 or RSA key pairs in your browser and gives you the OpenSSH public key for authorized_keys plus a PKCS#8 private key.

Ed25519 versus RSA

Ed25519 produces tiny, fast keys with strong security and is now widely supported, making it the recommended default. RSA remains the safe fallback for very old systems or strict environments; 4096-bit RSA offers a comparable security margin at the cost of slower handshakes.

Understanding the two outputs

The public key is written in OpenSSH format, the single line you paste into ~/.ssh/authorized_keys or a Git provider. The private key here is exported as a PKCS#8 PEM, which most modern tools accept; if your SSH client insists on the OpenSSH private format, convert it with ssh-keygen -p -m PEM on your machine.

How to use SSH Key Generator

  1. Choose Ed25519 or an RSA size.
  2. Optionally set a comment such as user@host.
  3. Generate the key and copy the public key to your server or Git provider.
  4. Save the private key securely and set restrictive file permissions.

Generate a key for CI to push to a repository.

3. Replacing a weak key

Rotate to Ed25519 for better security and smaller keys.

Tips for getting accurate results

  • Prefer Ed25519 unless you have a compatibility reason to use RSA.
  • Protect the private key file with chmod 600 on the machine that uses it.
  • Give each device its own key so you can revoke one without affecting the others.

Key takeaways

  • Ed25519 is the modern default; RSA is the compatibility choice.
  • Only the public key goes on the server.
  • The private key must stay secret and be permission-protected.

Frequently asked questions

Is Ed25519 supported everywhere?

On all current OpenSSH versions yes. Only very old clients lack it, which is why RSA remains an option.

Can my browser make Ed25519 keys?

Yes, where Web Crypto supports the algorithm. If it is unavailable the option is disabled and RSA is used.

Where do I put the public key?

In ~/.ssh/authorized_keys on the server, or in the SSH keys section of your Git host.

Why a PKCS#8 private key?

It is the portable format browsers can export. Convert to OpenSSH format if your client requires it.

Are my keys uploaded?

No. They are generated locally with the Web Crypto API.

Keys beat passwords for server access. This SSH key generator produces both the public key you install and the private key you guard. For email and signing keys, see our PGP key generator.
