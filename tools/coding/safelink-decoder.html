Safelink Decoder - Decode Redirect & Safelink URLs

Unwrap Google, Bing, Proofpoint, Yahoo and other redirect/safelink URLs back to the original target.

What is a safelink?

Email security gateways, search engines and social networks wrap outbound links in redirect URLs - Google’s /url?q=, Bing’s base64 /ck/a links, Proofpoint URLDefense and Yahoo’s RU= redirects are the common ones. The real destination hides inside parameters, base64 or special markers.

Wrappers handled

Google redirect links, Bing redirect links (base64), Proofpoint URLDefense, Yahoo search redirects, Facebook link shims, plus a generic fallback that checks the usual suspect parameters (url, u, q, target, redirect, dest, link...). Lines that are not wrapped are returned unchanged so you can paste mixed lists.

How to use Safelink Decoder

  1. Paste one wrapped URL per line
  2. Click Decode
  3. Copy the original URLs out of the right-hand box

Tips for getting accurate results

  • Bing links encode the target as base64 after an "a1" prefix - the decoder strips and decodes it
  • Proofpoint links wrap the URL between "__" and "$$" markers
  • If nothing is detected the URL is returned as-is so you never lose data

Frequently asked questions

Is this safe?

Decoding is passive string work - no network requests are made.

Why would a link be wrapped?

Security scanners rewrite links to check them; search engines use redirects for tracking clicks.
