Avro Schema Generator: Infer Structure From a JSON Sample

Apache Avro is the de-facto schema format for streaming pipelines, but writing a schema by hand is tedious. This Avro schema generator takes a JSON sample and infers a schema for you, including nested records, arrays and optional nullable fields.

How types are inferred

Null becomes the null type, booleans stay boolean, and numbers are split into int, long and double based on whether they are integers and how large they are. Strings map to string. Arrays become an Avro array whose items type is the union of the element types found in the sample. Nested objects become nested records with a generated, unique name.

Nullable unions

Avro has no concept of an optional field; you express it as a union with null. Enabling nullable fields wraps each type as ["null", type] and sets the default to null, which is compatible with many serialization frameworks that omit empty fields.

How to use Avro Schema Generator

  1. Paste a representative JSON object.
  2. Name the top-level record and, optionally, a namespace.
  3. Toggle nullable fields if your data may omit values.
  4. Copy the generated Avro schema into your pipeline.

Tips for getting accurate results

  • Use a sample that includes every field you expect, since inference only sees what you paste.
  • Review the inferred numeric types: ints that may grow should be long.
  • Enable nullable when the source data can omit a field.

Key takeaways

  • A JSON sample is enough to scaffold an Avro schema.
  • Nullable fields are unions with null and a null default.
  • Always review generated types against your real data contract.

Frequently asked questions

What is Apache Avro?

A row-oriented serialization format with a schema, widely used in streaming and big-data pipelines.

How are numbers typed?

Integers within the 32-bit range become int, larger integers become long, and non-integers become double.

Can Avro represent optional fields?

Yes, as a union that includes null, typically with a default of null. This tool can generate that form.

Does it validate my schema?

In validate mode it checks structural rules such as a record having a fields array with named, typed fields.

Is my data uploaded?

No. Conversion runs entirely in your browser.
