SAML Assertion Decoder: Read SSO Payloads Without a Debugger

When single sign-on fails, the answer is almost always hiding inside the SAML assertion - the XML document your identity provider sends after login. This SAML assertion decoder takes the Base64 SAMLResponse from your trace, decodes it, and pulls out the parts you actually care about: the subject, the issued claims, and the validity window.

Everything happens in your browser. No assertion is ever uploaded, which matters because a SAML response is a signed authentication token.

What the decoder extracts

The tool reads the first assertion and surfaces the Issuer, the NameID (who was authenticated), the Audience (which service provider the assertion is meant for), the status code, and every Attribute name in the attribute statement. It also shows the NotBefore and NotOnOrAfter timestamps so you can spot an expired token immediately.

Below the summary you get the full XML, pretty-printed with indentation, so you can read the raw structure or copy it into another tool.

Why decode a SAML response?

Common sign-in problems leave distinct fingerprints in the assertion. A clock skew shows up as a NotOnOrAfter that has already passed. A misconfigured audience shows the wrong service provider URL. A missing role attribute explains why a user signs in but sees no data. Reading the claims directly turns guesswork into a clear answer.

How to use SAML Assertion Decoder

  1. Copy the SAMLResponse value from your browser dev tools, proxy trace, or IdP logs.
  2. Paste it into the input box - either the raw Base64 or the decoded XML works.
  3. Read the summary tiles for Issuer, NameID, Audience and validity window.
  4. Review the pretty-printed XML below for the full attribute list.

Tips for getting accurate results

  • If the text starts with < it is already XML; the decoder treats it as such automatically.
  • A URL-encoded value that starts with SAMLResponse= is stripped for you.
  • Timestamps are shown in UTC; compare them against your server clock to check for skew.

Frequently asked questions

What is a SAML assertion?

It is an XML security token a SAML identity provider sends to a service provider to prove a user has authenticated, along with claims about the user.

Can I paste the raw Base64 value?

Yes. Paste either the Base64 SAMLResponse or the already-decoded XML; the tool detects which one you supplied.

Does it verify the signature?

No. This is an inspection tool. It decodes and displays the assertion but does not validate the XML signature, which requires the IdP certificate.

Why does my attribute list look empty?

Some responses put attributes in a separate encrypted assertion or in the top-level response rather than the first assertion. Check the full XML output.

Is it safe to paste a real assertion?

The decoding runs entirely in your browser. Even so, treat a live assertion as sensitive because it is a signed authentication token.

Conclusion

A SAML assertion decoder is the fastest way to understand why an SSO flow behaved the way it did. Decode the response, read the claims, and the root cause is usually on screen within seconds. For JWT-based flows, pair it with our JWT decoder.
