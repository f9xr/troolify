IPv4 Range Expander: From a Line to a Full Address List

Firewall rules, DHCP reservations and monitoring whitelists often want every address spelled out. This IPv4 range expander takes either a start-end range (192.168.0.1-192.168.0.10) or a CIDR block (10.0.0.0/28) and prints every address in it, one per line.

It all runs in your browser, and large blocks are capped so your tab never hangs.

Two ways to describe a block

Pass a.b.c.d-x.y.z.w for an explicit range, or a.b.c.d/prefix for a CIDR block. CDIR handles the math for you: 10.0.0.0/28 expands to the 16 addresses from 10.0.0.0 to 10.0.0.15, and the network address is normalized automatically.

A safety cap for sanity

Expansion stops at 4,096 addresses. A /20 or wider block is almost never what you actually wanted to print, and the cap keeps the output immediate while nudging you toward a more specific range.

Where the list goes

Copy the output straight into ACL entries, cloud security-group rules, DHCP reservations, or ipset configuration. The order is ascending and deterministic, so generated lists diff cleanly.

How to use IPv4 Range Expander

  1. Type a range like 192.168.0.1-192.168.0.10 or a CIDR block like 10.0.0.0/28.
  2. The expanded list appears live as you type, or press Expand.
  3. Copy the addresses for your ACL, firewall or reservation list.

Tips for getting accurate results

  • Both endpoints are included, so 192.168.0.1-192.168.0.3 yields three addresses.
  • For a CIDR block, the network address is aligned automatically; 10.0.0.5/28 expands from 10.0.0.0.
  • Overlapping or reversed ranges produce a clear error message instead of garbage.

Frequently asked questions

What formats are accepted?

Start-end like 192.168.0.1-192.168.0.10, or CIDR like 10.0.0.0/28. Spaces around the dash are fine.

Are both endpoints included?

Yes. A range from A to B always includes A and B.

How large can a range be?

Up to 4,096 addresses. Wider blocks return a friendly error instead of freezing the tab.

Does CIDR expansion align the network?

Yes — the network address is computed from the prefix, so 192.168.0.5/30 expands from 192.168.0.4.

Is anything sent to a server?

No. All expansion happens locally in your browser.

Conclusion

One line in, every address out. Reach for this IPv4 range expander whenever a device prefers explicit lists over notation, and use the subnet calculator when you need the network math, or the address converter for decimal, binary and hex forms.
