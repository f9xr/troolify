security.txt Generator: Publish a Clear Disclosure Path

Security researchers who find a bug on your site should not have to guess where to report it. The security.txt standard, RFC 9116, fixes that with a small text file at /.well-known/security.txt. This generator builds a valid one from a short form.

The fields that matter

Only two fields are required: a Contact and an Expires date. Everything else - Encryption for a PGP key, Policy for your disclosure rules, Acknowledgments, Preferred-Languages, Canonical, Hiring and CSAF - is optional but improves the experience for the reporter.

Keep it fresh

The expiry field is deliberately mandatory so stale files are noticed. RFC 9116 recommends an expiry less than a year in the future. This tool warns if the date is already past or set too far ahead, so the file stays trustworthy.

How to use security.txt Generator

  1. Add at least one Contact value and an Expires date.
  2. Fill in any optional fields such as Policy or Encryption.
  3. Review the issue count and fix anything flagged.
  4. Deploy the file at /.well-known/security.txt.

Tips for getting accurate results

  • Set an expiry within the next year and diarise the renewal.
  • Provide a PGP key if you expect encrypted reports.
  • List multiple contacts so reports are not lost to an inactive mailbox.

Key takeaways

  • security.txt lives at /.well-known/security.txt.
  • Contact and Expires are mandatory.
  • A fresh expiry keeps the file credible.

Frequently asked questions

Where does security.txt go?

At /.well-known/security.txt on your domain, with a copy at the root for legacy tooling if you wish.

Is a PGP key required?

No, but the Encryption field lets reporters encrypt sensitive details to your key.

How often should I update it?

Whenever your contacts or policy change, and at least annually to refresh the expiry.

Does this file improve security by itself?

No. It improves the disclosure process; the security work still happens in your code.

Is my data uploaded?

No. The file is generated in your browser.

Conclusion

Make it easy to report a problem and you get better reports. This security.txt generator produces a valid file you can deploy in seconds. Round out your hardening with a Content Security Policy.
