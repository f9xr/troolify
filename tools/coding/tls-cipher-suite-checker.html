TLS Cipher Suite Checker: See Which Suites Are Safe to Keep

Cipher suite lists age badly. A suite that was standard a decade ago is now a liability. This TLS cipher suite checker reads a list of IANA or OpenSSL names and rates each one, so you can trim a server config down to modern, forward-secret AEAD suites with confidence.

Reading a cipher suite name

The name tells you three things: the key exchange, the bulk cipher and the hash. ECDHE means ephemeral elliptic-curve Diffie-Hellman, which provides forward secrecy. AES_128_GCM or CHACHA20_POLY1305 are authenticated ciphers. TLS 1.3 suites drop the key exchange from the name because it is negotiated separately and always ephemeral.

What to keep and what to drop

Keep the TLS 1.3 suites and the TLS 1.2 AEAD suites with ECDHE. Drop anything using RC4, 3DES, DES, RC2, NULL or the anonymous and export families outright. CBC suites are not outright broken but are legacy; prefer GCM and ChaCha20 where the client supports them.

How to use TLS Cipher Suite Checker

  1. Copy the cipher list from your server config (nginx, Apache, OpenSSL, or a scanner report).
  2. Paste one suite name per line.
  3. Review the strength, protocol and forward-secrecy notes.
  4. Remove the weak and deprecated entries and re-test.

Tips for getting accurate results

  • Prioritise AEAD suites; avoid CBC unless a client requires it.
  • Forward secrecy protects past sessions if the private key leaks later.
  • Order matters too - put the strongest preferred suite first in your config.

Key takeaways

  • A cipher suite name encodes its key exchange, cipher and hash.
  • RC4, 3DES, DES, NULL and anonymous suites should be removed.
  • AEAD plus forward secrecy is the modern baseline.

Frequently asked questions

Are CBC ciphers broken?

Not broken, but they are legacy and more prone to implementation pitfalls. Prefer AEAD suites like GCM and ChaCha20.

What is forward secrecy?

It means each session uses an ephemeral key, so stealing the long-term private key does not decrypt past traffic. ECDHE and all TLS 1.3 suites provide it.

Does this tool connect to my server?

No. It analyses the names you paste. Use a scanner if you want to test a live endpoint.

What is the difference between IANA and OpenSSL names?

They describe the same suites with different spelling. This tool understands both.

Is a rating of OK a problem?

It means the suite works but is not an AEAD suite. It is acceptable, not ideal.

Conclusion

Fewer, stronger suites are easier to reason about and safer to run. This TLS cipher suite checker gives you a fast verdict on any list. Pair it with our CSP generator when hardening a site.
