Diff XML the Way Structure Dictates

XML documents are trees, so a meaningful XML diff compares elements, attributes and text - not visual lines. The Troolify XML Compare tool parses both documents with the browser's built-in XML parser and reports every change against an XPath-like path such as /catalog/book[1]/price.

Because XML is often pretty-printed by a formatter or a pipeline tool, two documents with identical data can look completely different. Toggle Re-indent mode and whitespace-only text nodes, indentation and attribute ordering are ignored, so the diff shows only real element, attribute and text changes.

How to Compare Two XML Files

  1. Paste your XML - original on the left, modified on the right.
  2. Toggle re-indent - keep it on when formatting should not matter (almost always the right call).
  3. Click Compare - both documents are validated, then walked node by node.
  4. Read the paths - elements, /@attributes and text changes appear color coded at full XPath-like paths.
  5. Copy the diff - grab a text summary for tickets, reviews or release notes.

What Re-Indent Mode Ignores

In re-indent mode the tool normalizes both trees before comparing: whitespace-only text nodes and indentation are removed, element text is trimmed, and attribute order is sorted. As a direct consequence, reformatting an XML file with a different indentation width produces zero diff entries, while changing a single price or adding a node produces exactly one.

Use Cases

Integration engineers verify that a SOAP response changed only in expected envelope fields, content teams diff RSS and sitemap files before deployment, Android developers review layout XML changes in pull requests, and Maven users confirm that a pom.xml update did not silently remove a plugin. Parsing and diffing run entirely locally in your tab.

Frequently Asked Questions

What does the re-indent option do?

Re-indent mode compares XML structurally: whitespace-only text nodes are ignored, text is trimmed, and attribute order is normalized. Formatting-only differences then disappear and only real element, attribute and text changes are shown.

What kinds of XML can I compare?

Any well-formed XML: SOAP payloads, REST responses, RSS and Atom feeds, sitemaps, Maven pom.xml files, Android layouts and Gradle metadata. The tool validates both documents first with the browser's built-in XML parser.

How are changes described?

Every change is reported with an XPath-like path such as /catalog/book[1]/price. Modified text appears as old → new, attributes use /@name syntax, and whole elements can be marked as added or removed.

Are my XML documents kept private?

Yes. Parsing and diffing run entirely in your browser. Nothing is uploaded, stored or sent to any server.

Conclusion

Whether you integrate SOAP services, publish feeds, build Android layouts or maintain Maven projects, the Troolify XML Compare tool pinpoints exactly what changed at a structural level - and with re-indent mode on, formatting noise never gets in the way. All in your browser.
