Turn Escape Sequences Back Into Readable Text

When data travels through JSON - API responses, webhook bodies, database exports - every newline becomes \n, every tab becomes \t, and every emoji or accented letter may become a \uXXXX sequence. Reading a payload like "caf\u00e9 \uD83D\uDE00" in a debugger is painful.

The Troolify JSON Unescape tool reverses the process. Paste the escaped string and it instantly decodes \", \\, \n, \r, \t, \b, \f, \/ and \uXXXX sequences - including surrogate pairs for emoji and astral characters - back into raw, human-readable text, live as you type.

How to Unescape a String

  1. Paste the escaped string - decoding starts immediately on every keystroke.
  2. Optionally strip outer quotes - if you pasted a complete JSON literal like "hello\nworld", enable this so the surrounding quotes are removed before decoding.
  3. Copy the result - grab the clean decoded text with the Copy button.

Invalid Escapes Are Explained, Not Guessed

If the input contains a dangling backslash, an unknown sequence such as \., or a \u escape that is missing its four hex digits, the tool stops and reports the exact position and the problem. That turns debugging a malformed payload into a quick fix instead of a guessing game.

Use Cases

Developers debug escaped API logs, decode webhook payloads for inspection, read double-escaped strings from data pipelines, and convert unicode-escaped content into searchable plain text. Because decoding runs in your browser, sensitive payload content never leaves your machine.

Frequently Asked Questions

What escape sequences does the tool decode?

The tool reverses \", \\, \b, \f, \n, \r, \t, \/ and \uXXXX Unicode escapes, including four-hex surrogate pairs such as \uD83D\uDE00. Unknown escapes are reported with their exact position.

What if my input is a full JSON string with outer quotes?

Enable the Strip outer quotes option and the tool removes a leading and trailing double quote before decoding, so a complete JSON string literal like "hello\nworld" decodes to hello + newline + world in one step.

What happens on an invalid escape?

The tool stops and shows an error describing the problem - a dangling backslash, an unknown sequence like \. or a \u escape without four hex digits - so you can fix the offending string instead of guessing.

Is the decoding done locally?

Yes. All decoding is done with JavaScript in your browser tab. Nothing is uploaded, stored or sent to any server.

Conclusion

Every developer eventually faces a wall of backslash-escaped text. The Troolify JSON Unescape tool makes it instantly readable, catches malformed escapes before they bite you, and does it all locally in your browser.
