Image Size Finder: Every Detail, No Upload

Whether you are checking an asset for a responsive breakpoint, verifying a banner meets a client’s spec, or auditing images before a build, you need the exact pixels and proportions - fast. The Troolify Image Size Finder reads image files straight from your device or a URL and reports width, height, aspect ratio, megapixels, color depth and exact file size, all locally.

How It Works

Drop a JPG, PNG, GIF, WebP, BMP or SVG onto the zone - or paste a URL. Your browser reads the file, opens it as an image, and samples the canvas to determine color depth. Because the format is detected from the file signature, even images with misnamed extensions are identified correctly.

What You Get Back

  • Dimensions - exact pixel width and height.
  • Aspect ratio - simplified fraction (1920 × 1080 becomes 16:9) plus the decimal ratio.
  • Megapixels - pixel area expressed in mega-pixels.
  • Color depth - 24-bit RGB or 32-bit ARGB, detected from real transparency.
  • File size - shown in B, KB and MB alongside the MIME type.

Common Uses

Designers confirm an exported asset meets a client’s exact pixel spec. Developers verify hero images match required dimensions before a deployment. Anyone can satisfy a form that asks for an image “exactly 1200 by 630 pixels” without opening a graphics editor.

Frequently Asked Questions

What image formats are supported?

JPEG, PNG, GIF, WebP, BMP and SVG. The finder reads format signatures on your side, so it does not rely on the file extension.

Do you upload my image to check its size?

No. Everything runs in your browser. Files never leave your device and URL images are fetched directly by your browser.

How is the aspect ratio calculated?

The width and height are reduced by their greatest common divisor, so 1920 x 1080 becomes 16:9, then shown as a decimal ratio as well.

How does color depth detection work?

The image is drawn to a canvas and pixels are sampled. If any sampled pixel has partial transparency the image is reported as 32-bit (ARGB); otherwise 24-bit (RGB). SVGs are vector graphics and have no bit depth.

Conclusion

One drop, every answer - dimensions, ratio, megapixels, color depth and size - computed locally, with a small history so you can compare the last few images in a row.
