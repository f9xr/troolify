Double-Encoded JSON Is Everywhere
Webhook deliverers, queue workers and structured loggers frequently wrap one JSON document inside another. The inner payload arrives as a JSON string - quoted and backslash-escaped - so its field names and content become a wall of \" sequences that no amount of squinting can untangle.
The Troolify Unstringify JSON tool unwraps that stack automatically. Paste the stringified blob, hit Unstringify & Format, and it keeps decoding while a parsed value is still a string containing JSON - up to five levels - then pretty-prints the innermost document with syntax highlighting, all in your browser.
How to Use
  1. Paste the blob - either a fully stringified payload or a payload that is only one level deep.
  2. Decode - the tool reports how many nesting levels it unwrapped and the top-level type (object, array or plain string).
  3. Adjust - disable Auto-detect to decode only one outer level; disable Pretty-print to keep the output compact and minified.
  4. Export - copy the result or download it as a .json file.
Clear Errors, Real Diagnostics
If the top-level input is not valid JSON, the tool says so immediately with the parser message. Otherwise the output line shows the unwrapped depth (for example, "Decoded through 2 levels") alongside the top-level type, so you always know exactly what the decoder did.
Use Cases
Debug Stripe and webhook payloads, inspect double-encoded entries in log aggregators, re-read cached API responses, and turn JSON stored as a string in a database into an inspectable, diffable document.
Frequently Asked Questions
What does stringified JSON mean?
A JSON document stored inside a JSON string, with every quote and backslash escaped. It is common in webhook payloads and structured log lines, and it is nearly impossible to read by eye - which is exactly what this tool decodes.
How many nesting levels are decoded?
With Auto-detect enabled the tool keeps unwrapping up to 5 levels while the parsed value is still a string containing JSON. Turn Auto-detect off to decode only a single outer level.
What does Pretty-print do?
It re-indents the decoded document with a two-space indent and colour-codes keys, strings, numbers and booleans. Untick it to produce the same document in compact, minified single-line form.
Is my data uploaded anywhere?
No. Decoding runs entirely in your browser and nothing leaves your machine - the tool is 100% client-side with zero data retention.
Conclusion
Reading nested, escaped JSON by eye wastes time that debugging should not cost. Unstringify JSON peels away each layer, shows its work, and hands you a clean, highlighted document - instantly, privately, and in your own browser.
