HTML WYSIWYG Editor - Rich Text to HTML

Edit rich text with a formatting toolbar and see the clean HTML output instantly.

A tiny rich-text editor

This editor wraps a contenteditable region with the classic formatting commands - bold, italic, headings, lists, quotes, links and images. Every keystroke syncs clean HTML you can copy into a CMS, email or static site.

Two views, one document

Flip to the HTML source with the </> button to hand-tweak the markup; switching back re-parses it into the visual view. The Copy and Download buttons always export the current HTML.

How to use HTML WYSIWYG Editor

  1. Format your text with the toolbar
  2. Toggle the source view if you want raw HTML control
  3. Copy the HTML or download it as a standalone .html file

Tips for getting accurate results

  • Links and images need full https:// URLs
  • The export wraps your content in a minimal valid HTML document
  • Formatting uses execCommand - simple, dependency-free and supported by all evergreen browsers

Frequently asked questions

Is my content stored?

No. Everything lives in the page until you copy or download it.

Why execCommand if it is deprecated?

It still works everywhere; the modern Selection/Clipboard APIs do not yet cover all these commands.
