JSON to TOML Converter: From Bracket Town to Config Country

TOML is the configuration format of the Rust and Python eras: small, typed, and readable. This JSON to TOML converter maps any JSON document onto that shape, turning objects into [tables], arrays of objects into [[array of tables]], and keeping scalars typed.

Everything runs in your browser, so configuration never leaves your machine.

How objects and arrays are mapped

A JSON object becomes a TOML table: {"database":{"host":"localhost"}} becomes [database] followed by host = "localhost". Arrays of primitives stay inline (tags = ["web","tools"]) while arrays of objects become repeated [[servers]] blocks, one per item. Nested objects inside those blocks are emitted as sub-tables such as [servers.deploy].

Types are preserved

Strings stay quoted, numbers stay bare, and booleans become true/false. Values that have no TOML equivalent, like null, are skipped so the output always parses with a real TOML parser.

Escaping inside strings

Quotes and backslashes inside string values are escaped according to the TOML spec (\", \\), and newlines, tabs and carriage returns become \n, \t and \r so multi-line values survive the trip.

How to use JSON to TOML

  1. Paste a JSON object or array into the input box.
  2. The TOML output appears live as you type, or press Convert.
  3. Copy the result into your Cargo.toml, pyproject.toml or server config.

Tips for getting accurate results

  • Keys with dots or spaces are quoted automatically so the output stays valid.
  • The output is deterministic: identical JSON always yields identical TOML.
  • Arrays mixing objects and scalars are emitted inline; use uniform arrays of objects for [[tables]].

Frequently asked questions

What happens to nested objects?

Each nested object becomes its own [table] section, with deeper nesting producing dotted headers such as [database.pool].

How are arrays handled?

Arrays of primitives stay inline as [a, b, c]. Arrays of objects become repeated [[name]] blocks, which is the idiomatic TOML shape.

What about null values?

TOML has no null literal, so null and undefined values are omitted from the output.

Are strings escaped correctly?

Yes: quotes, backslashes, newlines and tabs are escaped per the TOML spec, so hostile or multi-line values parse cleanly on the other side.

Is my data uploaded?

No. The entire conversion runs inside your browser.
