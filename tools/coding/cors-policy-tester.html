CORS Policy Tester: Understand Why a Request Is Blocked

Every developer has stared at a CORS error in the console. This CORS policy tester takes a request and a response policy and walks through the browser's checks one by one, so the reason for a block is explicit rather than a guess.

Simple requests versus preflight

A simple request (GET, POST or HEAD with only safe headers) is sent directly. Anything else triggers a preflight OPTIONS request first, and the browser checks the allowed origins, methods and headers before sending the real request. The tester detects which path your request takes.

The credentials wildcard trap

The most common CORS bug is pairing Access-Control-Allow-Origin: * with credentials. Browsers forbid that combination. The fix is to echo the specific origin and set Access-Control-Allow-Credentials: true, which the tester flags for you.

How to use CORS Policy Tester

  1. Enter the request origin, method and any custom headers.
  2. Enter the Access-Control headers your server returns.
  3. Read the pass or block verdict and the per-check explanation.
  4. Apply the suggested response headers and re-test.

Tips for getting accurate results

  • Match origins exactly, including scheme and port.
  • Avoid wildcards when credentials are involved.
  • Cache preflights with Access-Control-Max-Age to cut round trips.

Key takeaways

  • Custom methods and headers trigger a preflight.
  • The origin wildcard is incompatible with credentials.
  • A step-by-step check turns a cryptic error into a clear fix.

Frequently asked questions

What triggers a preflight?

Any request that is not simple: a method outside GET, POST and HEAD, or a custom header such as Authorization.

Why can I not use * with credentials?

The specification forbids it because it would let any origin read authenticated responses. Echo the exact origin instead.

Does this send a real request?

No. It simulates the browser checks against the policy you enter, so you can reason about headers without a server.

How long can a preflight be cached?

Whatever you set in Access-Control-Max-Age, up to the browser limit. Longer values reduce preflight traffic.

Is my configuration uploaded?

No. Everything runs in your browser.
