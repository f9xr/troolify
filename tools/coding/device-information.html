Device Information - Browser, Screen & Hardware Details

See your browser, screen, hardware and network details - all reported by this tab.

What your browser reports

Every page you visit can read a surprising amount of device information: screen size, pixel ratio, language, time zone, CPU cores and more. This tool shows exactly what this tab exposes - useful for QA, support and privacy awareness.

Privacy note

Combined, these properties form a partial fingerprint that can help track you across sites. Nothing here leaves your browser on this page, but be aware that other sites read the same data.

How to use Device Information

  1. Review the tiles - they update instantly from browser APIs
  2. Click any tile to copy that value
  3. Use Copy all for a full text dump when filing a bug report

Tips for getting accurate results

  • Resize the window and hit Refresh to see new window dimensions
  • Some values (device memory, connection) are only exposed by some browsers
  • Headless browsers and privacy modes report reduced information

Frequently asked questions

Does this upload my device data?

No. Everything is read and displayed locally.

Why is some information "-"?

The browser only exposes certain values on secure contexts or specific engines.
