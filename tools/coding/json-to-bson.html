JSON to BSON: MongoDB Binary Documents in Your Browser

MongoDB stores documents in BSON (Binary JSON), a compact binary format that encodes the length of each field inline and supports data types plain JSON cannot express. The Troolify JSON to BSON converter serializes any JSON document into real BSON bytes right in your browser, then shows you the hex dump, base64 string and exact byte count.

What the JSON to BSON Converter Does

The tool parses your JSON and encodes it using the BSON specification: documents and arrays (type 0x04), strings (0x02), int32 (0x10), doubles (0x01), booleans (0x08), int64 where values exceed the 32-bit range, and null (0x0A). Every element is length-prefixed just as MongoDB would serialize it on the wire.

How to Use the JSON to BSON Converter

  1. Paste your JSON - or load the sample document to see it in action.
  2. Click Serialize - the tool encodes the document to BSON.
  3. Read the hex dump - byte offsets, element types and sizes at a glance.
  4. Grab base64 or plain hex - copy either representation for your tests.
  5. Check the byte count - know the exact wire size of your document.

Use Cases

Backend developers compare the exact bytes their driver produces. QA engineers build test fixtures that simulate MongoDB documents. Students learning the BSON spec can read every element side by side with the source JSON. Anyone debugging EJSON projections or binary payloads gets a precise, inspectable byte stream.

Frequently Asked Questions

What is BSON?

BSON (Binary JSON) is MongoDB's binary serialization format for documents. It stores the length of each element inline, making traversal fast, and supports richer data types than plain JSON such as ObjectId, Date and Binary data.

What BSON types does this converter support?

The converter implements the core BSON types: document, array, string, boolean, int32, int64, double, null. ISO 8601 date strings are serialized with the date type. Nested objects and arrays are handled recursively.

Is my JSON uploaded anywhere?

No. The BSON serialization runs entirely in your browser using JavaScript. Nothing is uploaded or stored on any server.

How are hex dumps and base64 computed?

After building the BSON byte array, the tool formats the bytes into a readable hex dump with byte offsets, a plain hex string and a base64 string. The byte count reflects the exact wire size of the document.

Conclusion

Whether you are verifying driver output, building MongoDB test fixtures or learning the BSON spec, the Troolify JSON to BSON converter gives you exact binary serialization with inspectable hex, base64 and byte counts in seconds - entirely in your browser.
