User Agent Finder: See Your Browser Identity

Your user agent tells websites your browser, engine and platform. This user agent finder shows the raw string plus useful parsed details.

What a user agent is

Every request carries a user agent string. It helps servers serve the right content and is used for analytics and bot detection.

Privacy note

User agents add fingerprinting entropy. Some browsers reduce or freeze them for privacy; yours may differ from your real device.

How to use User Agent Finder

  1. Press Show my user agent.
  2. Review the string and details.
  3. Copy it if you need to report it.

Tips for getting accurate results

  • UA strings are spoofable.
  • Do not paste them publicly with other data.
  • Browsers may freeze values.

Key takeaways

  • The UA identifies your browser.
  • It is used for compatibility.
  • It is not a reliable identifier.
