Query Any JSON Like a Database

      
JSONPath is the XPath of the JSON world - a compact way to reach deep inside a nested document. Where manual traversal means chained loops and defensive checks, a single expression such as $.store.book[*].author hands you every author at once.

      
The Troolify JSONPath Tester evaluates your expressions live as you type. Paste a document, pick a preset or write your own path, and the matched values appear instantly with their count and the evaluation time.

      
Supported Syntax

      
    
        
  • $ - the root of the document.
    • 
        
  • $.store.book - child lookups through dotted keys.
    • 
        
  • [0], ['isbn'] - array indexes and quoted keys.
    • 
        
  • [*] - every element of an array or every value of an object.
    • 
        
  • $..price - recursive descent for a key at any depth.
    • 
        
  • [?(@.price < 10)] - filters with ==, !=, <, <=, >, >= and truthiness tests.

Built for API Work

      
When you integrate with a REST service and need one field from a nested response, this tester is the fastest way to confirm the path before you write it in code. It runs entirely in your browser, so sensitive response bodies are never uploaded.

      
Frequently Asked Questions

      
Which JSONPath syntax is supported?
The tool supports $ for the root, child lookups like $.store, array indexes such as [0], the wildcard [*], quoted keys like ['key'], recursive descent with $..price, and filters such as ?(@.price<10) with ==, !=, <, <=, >, >= and truthiness checks.

      
Does the tester run live?
Yes. Results re-evaluate automatically about 300 ms after you stop typing in either box, and the Evaluate button forces an immediate run whenever you want it.

      
How are results reported?
Every matched value is returned as a JSON array with syntax highlighting, together with the number of matches and the evaluation time in milliseconds.

      
Is my JSON uploaded anywhere?
No. The JSON document and the expression are evaluated entirely in your browser. Nothing is sent to a server and no data is retained.

      
Conclusion

      
Reaching into a deeply nested JSON response should be a one-liner, not a debugging session. The Troolify JSONPath Tester makes every lookup instant, verifiable and private - type, and watch the matches appear.
