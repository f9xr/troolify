URL Encoder & Decoder: Ship Any Text in a Link

Browsers and servers only understand a small, safe alphabet inside a URL. When your headline, search term, or shop name contains a space, an apostrophe, or any non-ASCII character, it must be converted to a percent-encoded form before it goes into a link or query string. This tool performs that conversion in both directions, instantly and privately.

What Is Percent-Encoding?

Percent-encoding replaces unsafe characters with a percent sign followed by their two-digit hexadecimal code. A space becomes %20, an ampersand becomes %26, and the letter é becomes %C3%A9 because it occupies two UTF-8 bytes. Only A-Z, a-z, 0-9 and a handful of safe symbols pass through unchanged.

How to Use This Tool

  1. Pick a direction - Encode for text going into a URL, or Decode for percent-encoded text coming out of one.
  2. Paste your input - the result updates live as you type.
  3. Copy the output into a link, redirect target, or fetch call.

The encoder uses encodeURIComponent, which is the correct variant for individual query-parameter values - it escapes /, :, & and #, which a plain URL would otherwise break.

Where Developers Need It

Building a ?q= search link, passing values through a redirect, emailing a deep link to a product page, or serialising user input into an API request - all of these need percent-encoding. Pair it with the Base64 Encoder & Decoder when you need compact transport encoding, or the HTML Entity Encoder for text going into markup instead of URLs.

Diagnosing Decode Errors

Malformed input such as a stray % at the end of a string does not decode cleanly. When that happens this tool reports the problem in the status line below the output instead of returning garbage, so you can fix the source value and retry.

Frequently Asked Questions

What is URL encoding?

URL encoding (percent-encoding) converts unsafe characters - spaces, quotes, non-ASCII letters, emoji - into a percent sign followed by two hex digits, so any text can ride safely inside a link or query string.

What is the difference between encodeURIComponent and encodeURI?

encodeURI leaves URL structure characters like / : ? & # intact and suits whole URLs, while encodeURIComponent escapes everything except a few safe symbols and suits individual query values. This tool uses the component variant, which is what query parameters need.

Why does encoded text show %20 and %C3%A9?

%20 is a space and %C3%A9 is the UTF-8 encoding of é. Percent-encoding works byte by byte, so non-ASCII letters expand into multiple encoded bytes.

Is this URL encoder safe to use?

Yes. Everything runs locally in your browser tab - your text is never uploaded or transmitted, and nothing is stored after you close the page.

Conclusion

Percent-encoding looks cryptic but follows simple rules, and this tool applies them perfectly every time. Copy a decoded parameter, encode a query value, and move on - your data stays on your machine throughout.
