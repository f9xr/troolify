TOML to YAML: Swap One Indentation Dialect for Another

TOML and YAML both encode nested configuration, just with different accents. This TOML to YAML converter parses a TOML file and re-emits it as two-space-indented YAML, translating tables into mappings and [[array of tables]] into sequences of mappings.

Conversion stays local, so your config never leaves the tab.

What maps to what

A TOML table ([database]) becomes a nested YAML mapping (database:), scalars stay scalars, inline arrays become YAML flow sequences, and each entry in a [[servers]] array becomes a - name: ... list item in a YAML sequence.

Quoting rules

Strings that look like numbers, booleans or nulls, or that contain colons, hashes or braces, are quoted automatically so the YAML means the same thing as the TOML. Plain, safe strings stay unquoted for readability.

Lossless for config use

Key order is preserved, empty tables become {}, and dates remain strings. The result is deterministic, which makes infrastructure-as-code diffs pleasant to review.

How to use TOML to YAML

  1. Paste a TOML file into the input box.
  2. The YAML appears live as you type, or press Convert.
  3. Copy it into your Docker Compose, Ansible or Helm-style configs.

Tips for getting accurate results

  • Strings containing special characters are quoted for you; check tool-generated configs visually once before deploying.
  • Dotted headers such as [a.b] become nested mappings.
  • Multi-line strings are escaped into single-line YAML quoted strings.

Frequently asked questions

How are TOML tables converted?

A [table] header becomes a nested YAML mapping, with dotted headers producing deeper nesting.

What happens to [[array of tables]]?

Each block becomes one item in a YAML sequence of mappings, rendered with dash lines.

Are strings re-quoted?

Only when needed: values that could be misinterpreted (numbers, booleans, colons, hashes) are quoted automatically.

Is key order kept?

Yes. The YAML follows the exact order of the TOML input.

Does it run online?

No — the whole conversion runs in your browser.

Conclusion

Config formats are a matter of taste, but machines only accept what they accept. If the playground wants YAML and the source of truth is TOML, this TOML to YAML converter is the bridge. The reverse trip is on the YAML to TOML page.
