CSS Inliner

The CSS Inliner takes a separate stylesheet and pushes matching rules into each element's style attribute - the technique email clients rely on, since most strip head styles and class sheets.

How to Use

  1. Paste your HTML into the top box.
  2. Paste your CSS into the bottom box.
  3. Click Inline styles - the styled HTML comes back ready to paste.

Why It Matters

Newsletter tools, landers and drag-drop builders behave differently on head styles; inline style attributes survive everywhere. Moving the CSS inline keeps the same look without rewriting a template by hand.

Contractor Tip

Run your CSS through a formatter first - selectors with pseudo-classes like :hover are skipped rather than crashing, so keep those in a separate stylesheet.

Frequently Asked Questions

Which selectors are inlined?

Simple type, class, id and descendant selectors are matched against the DOM; pseudo and universal selectors are skipped.

Conclusion

Inline your CSS into matched HTML elements instantly - email-safe styling without a server call.
