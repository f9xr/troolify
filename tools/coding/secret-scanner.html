Secret Scanner: Catch Leaked Keys Before They Spread

A secret committed once can live forever in git history and a pasted log. This secret scanner reads text, code or config and flags the credential formats that attackers grep for, from AWS keys to private key blocks, without ever sending the content anywhere.

What it looks for

The scanner recognises structured secrets such as AWS access key IDs, GitHub and Stripe tokens, OpenAI keys, Slack and SendGrid tokens, Google API keys, Twilio SIDs and JSON Web Tokens. It also detects PEM private-key blocks and generic api_key = ... assignments. Matches are masked so the tool does not re-expose the full value on screen.

What to do when you find one

Finding a secret is step one. Rotate the credential immediately, remove it from the code, and purge it from history. A match can also be a false positive, so confirm before acting - but rotate first if you are unsure.

How to use Secret Scanner

  1. Paste the file, log or diff you want to check.
  2. Review the findings sorted by severity with masked values.
  3. Note the line numbers and confirm each hit.
  4. Rotate any real secret and remove it from the source.

Tips for getting accurate results

  • Rotate first, investigate second, if a hit looks real.
  • Add the patterns that matter most to your pre-commit hooks.
  • Remember that obfuscated or split secrets can evade pattern matching.

Key takeaways

  • Pattern matching finds the common, structured leaks fast.
  • Masking keeps the review from spreading the secret further.
  • A clean scan is not a guarantee; review sensitive text manually.

Frequently asked questions

Can it find every secret?

No. It matches known formats. Custom or split secrets may be missed, so treat a clean result as a hint, not a certification.

Will it expose my secrets?

Matches are masked and nothing is uploaded, but avoid pasting production secrets unnecessarily.

What are the severity levels?

Private keys and provider tokens are critical or high because they grant direct access. Generic assignments and JWTs are lower.

Does it scan files?

Paste the file contents into the box. Everything is processed locally.

Should I rotate a flagged key?

If it looks like a real, live credential, rotate it. Better safe than exposed.

Conclusion

Secrets leak through small slips. This secret scanner catches them in seconds. When you have hashed replacements, verify key storage with our API key hasher.
