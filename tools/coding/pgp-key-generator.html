PGP Key Generator: Encryption Keys Without the Command Line

OpenPGP keys encrypt email, sign releases and prove authorship. Generating one usually means a terminal and a set of flags. This PGP key generator creates a modern Curve25519 or RSA key pair right in your browser, with an optional passphrase and a revocation certificate.

Curve25519 or RSA?

Curve25519 is smaller and faster while offering strong security, which is why it is the recommended default. RSA at 4096-bit is the conservative choice for maximum compatibility with older systems. Both are perfectly usable; pick Curve25519 unless you know a recipient needs RSA.

Protect the private key

A passphrase encrypts the private key at rest, so a stolen file is not immediately usable. The revocation certificate lets you announce that a key is compromised; generate it now and store it separately from the private key.

How to use PGP Key Generator

  1. Enter a name and email for the key identity.
  2. Choose Curve25519 or RSA and set an optional passphrase.
  3. Click Generate and wait for the key to be produced.
  4. Store the private key and revocation certificate somewhere safe.

Tips for getting accurate results

  • Use a strong passphrase; the key file alone should not be enough.
  • Back up the revocation certificate separately from the private key.
  • Publish only the public key, ideally on a keyserver or your own site.

Key takeaways

  • Curve25519 is the modern default; RSA is the compatibility choice.
  • A passphrase protects the private key at rest.
  • Keep the revocation certificate ready in case the key leaks.

Frequently asked questions

What is a revocation certificate?

A pre-signed statement that withdraws your key. Publishing it tells others to stop using the key if it is compromised or lost.

Is a passphrase required?

No, but it is strongly recommended so the private key file is not usable if stolen.

Where should I store the private key?

Offline or in an encrypted store, never in plain source control or an unencrypted cloud drive.

Are keys sent to a server?

No. Generation runs in your browser using the OpenPGP library.

Which key type should I pick?

Curve25519 unless you must interoperate with a system that only accepts RSA.

Conclusion

An OpenPGP key is a long-term identity - generate it carefully. This PGP key generator makes modern keys without a terminal. For SSH access, use our SSH key generator.
