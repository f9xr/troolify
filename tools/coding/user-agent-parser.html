User Agent Parser - Parse Browser & Device from User Agent

Break a browser user agent string into browser, engine, OS and device details.

Anatomy of a user agent

A user agent string packs four things into one line: the browser and version, the rendering engine, the operating system, and a device hint. This parser separates them with ordered rules so Edge beats Chrome and Safari detection stays accurate.

Why parse user agents?

Debugging analytics, tailoring download links, spotting outdated browsers, or filtering bot traffic. For anything security-sensitive remember user agents are trivially spoofed - treat them as hints, not identity.

How to use User Agent Parser

  1. Paste a user agent string (or click "Use my UA")
  2. Click Parse to split it into browser, engine, OS and device
  3. Copy the JSON for your notes or bug reports

Tips for getting accurate results

  • Browsers fork often - Edge and Opera pretend to be Chrome, so rule order matters
  • User agents can be spoofed; never use them for authentication
  • Device detection is a guess based on keywords like "Mobile" and "iPad"

Frequently asked questions

Does it detect bots?

Yes - common bot/crawler/curl signatures are flagged.

Is the input stored?

No, parsing happens locally in your browser.
