YAML and JSON, interconverted

YAML is the human-friendly format for configs (CI pipelines, Docker Compose, Kubernetes); JSON is what APIs speak. This converter uses the js-yaml parser - the same library behind countless build tools - so nested maps, arrays, numbers, booleans and nulls all map correctly.

Error reporting

YAML is strict about indentation. When a document fails to parse, the tool reports the parser’s message (shown without the multi-line stack) so you can fix tabs/spaces or quote problems quickly.

How to use YAML to JSON Converter

  1. Paste your YAML on the left (or hit Sample)
  2. Choose 2, 4 or tab indentation
  3. Click Convert and copy the JSON

Tips for getting accurate results

  • Tabs are not valid YAML indentation - use spaces
  • Strings that look like numbers are converted to number types - quote them to keep them text
  • Ctrl/Cmd+Enter triggers the conversion from the input box

Frequently asked questions

Is my YAML uploaded?

No. The parser library loads from a CDN once, then all parsing is local.

Does it support multi-document YAML?

Only the first document of a multi-doc stream is converted.
