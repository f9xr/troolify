TOML to JSON Converter: Config Files, Meet the Web

TOML is lovely to read but tools and APIs speak JSON. This TOML to JSON converter parses TOML files and prints the result as indented JSON, handling table headers, [[array of tables]], inline tables, arrays and comments.

The parser runs entirely in your browser, so nothing is uploaded.

What the parser understands

Plain key = value pairs, [table] and [a.b.c] dotted headers, [[array.of.tables]] blocks, inline tables such as { min = 2, max = 8 }, single and multi-line strings, integer formats (0x, 0o, 0b, underscores), floats, booleans and comments beginning with #.

How types come across

Numbers stay numbers, booleans stay booleans, and strings stay strings. Dates and times such as 1979-05-27T07:32:00Z are preserved as strings so they survive round-trips into JSON without timezone surprises.

Readable, deterministic output

The output is pretty-printed with two-space indentation and key order preserved exactly as written, which makes diffs between versions of the same config meaningful.

How to use TOML to JSON

  1. Paste a TOML file (Cargo.toml, pyproject.toml, server config) into the input box.
  2. The JSON appears live as you type, or press Convert.
  3. Copy the JSON for your API, dashboard or CI pipeline.

Tips for getting accurate results

  • Comments are stripped automatically; only actual data becomes JSON.
  • Dotted keys like a.b.c = 1 become nested objects.
  • Duplicate keys follow the last-value-wins rule, matching mainstream TOML parsers.

Frequently asked questions

Does it handle [table] headers?

Yes. Each header becomes a nested object, and dotted headers such as [a.b] nest further.

What about [[array of tables]]?

Each block becomes one object in a JSON array under its header name.

Are dates converted?

Date-times and dates are kept as strings so they stay lossless and timezone-safe.

Are comments preserved?

No — comments are stripped during parsing. Only key/value data appears in the JSON.

Is my data uploaded?

No. Parsing happens entirely inside your browser.

Conclusion

TOML is a great source of truth; JSON is a great transport. Run your config through this TOML to JSON converter whenever the consuming system prefers brackets, and go back the other way with JSON to TOML. YAML fans can also use JSON to YAML.
