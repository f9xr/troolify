Image to Base64: Embed Images Directly in HTML & CSS

A data URL is an image encoded as plain text. Instead of a browser requesting logo.png from a server, the whole image travels inside the HTML or CSS itself. That trick powers self-contained emails, single-file web pages, and tools that exchange images without a file host - and it is exactly what this converter produces.

What Is a Base64 Data URL?

A data URL looks like this: data:image/png;base64,iVBORw0KGgoAA.... The first part names the MIME type, and the long text that follows is the image's file content encoded in base64. Because it is a self-contained string, it can replace a file path wherever HTML or CSS accepts one.

  1. Upload an image - PNG, JPEG, WebP or GIF all work.
  2. Watch the conversion happen - the data URL is generated instantly with the FileReader API.
  3. Copy the text - hit the copy button and paste it into your project.
  4. Use it anywhere - img src, CSS background-image, email HTML, or JSON payloads.

When to Embed vs. Link an Image

Embedding shines for small assets: favicons, buttons, and inline SVGs-style branding that must survive a single-file build or an email that blocks external downloads. The cost is size - base64 inflates payloads by about 33%, and those bytes cannot be cached separately. For regular website images, keep using normal files and let your browser cache them. Frequently Asked Questions

What is a base64 image data URL?

A base64 data URL encodes the image's binary data as text and bundles it together with the MIME type, for example data:image/png;base64,iVBORw0KGgo... It can be used directly in an HTML img src attribute or a CSS background-image property, avoiding a separate file request.

When should I embed an image as base64?

Embedding makes sense for tiny assets such as icons, logos and small graphics, especially ones included in email, offline pages, or single-file builds. For regular website images, a separate file is usually better because it can be cached and loads in parallel.

Does base64 increase the file size?

Yes. Base64 encoding grows the payload by roughly 33% compared with the original binary file, so a 15 KB image becomes about 20 KB of data URL text. This is why the technique is best reserved for small images.

Is the Troolify base64 converter safe to use?

Conclusion
