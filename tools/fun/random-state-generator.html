Random State Generator: Pick One of the 50 US States

Need to pick a state at random - for a road-trip roulette, a classroom draw or a writing prompt? This random state generator returns a fair pick from all fifty US states and can show the two-letter abbreviation and capital alongside it.

A fair pick from all fifty

The generator draws uniformly from the complete list of 50 states, so no state is more likely than another. Toggle the detail level to show just the state name, the name with its USPS abbreviation, or the full line including the capital city. Because the pick is shown in a tile, you can request several at once and get a distinct shortlist - the tool avoids repeating the same state inside a single run.

What people use it for

Teachers use it to assign a state project without playing favourites. Writers use it to place a scene somewhere unexpected. Game nights use it as a spinner for travel-themed challenges. And when you simply cannot decide where to visit next, letting the generator choose removes the deliberation.

How to use Random State Generator

  1. Choose how much detail to show: name only, name and abbreviation, or the full line with the capital.
  2. Set the number of states to draw.
  3. Press Generate.
  4. Copy the list if you want to keep or share it.

Frequently asked questions

Is every state equally likely?

Yes. The generator draws uniformly from the complete set of 50 states.

Does it include Washington, D.C.?

No. The pool is the 50 states; the District of Columbia is not a state.

Can it show the capital city?

Yes. Pick the full detail level and each pick shows the state, its abbreviation and its capital.

Will I get the same state twice?

Not within one run - the generator avoids duplicates until you have drawn every state.

Do you store my picks?

No. Everything is generated in your browser and nothing is saved.
