Dragonborn Name Generator: Given Names and Clan Names for D&D

Dragonborn naming has its own logic: a personal given name followed by a clan name, spoken with pride. This Dragonborn name generator produces that pattern with masculine and feminine given names and a deep pool of clan names, ready for your D&D character sheet or campaign.

Given name plus clan name

A Dragonborn introduces themselves by given name and clan - "Balasar Myastan". The given name is personal and short; the clan name is what the world remembers, and it can carry honour or shame depending on the clan's history. The generator lets you draw a random clan or pin a specific one, which is useful when you already know your character's family background.

Using it at the table

Generate a handful of names and keep the ones you did not pick as NPCs from the same clan - instantly you have relatives, rivals and allies who sound like they belong together. Because the naming style is consistent, a whole campaign's worth of Dragonborn feels like one culture rather than a random list.

How to use Dragonborn Name Generator

  1. Choose the gender and, optionally, a clan.
  2. Set how many names you want.
  3. Press Generate.
  4. Copy the names for your character or NPC roster.
