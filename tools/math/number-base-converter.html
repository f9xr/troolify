Number Base Converter: Read and Write Any of the Four Key Bases

Binary on a network config, hexadecimal in a colour picker, octal in a file-permission string and decimal on a receipt - numbers change their clothes depending on the situation. This converter translates between all four instantly and shows every representation of each value at the same time.

What Is a Radix, or Base?

The radix is simply how many distinct digits a number system has. In base 10 you count with ten symbols (0-9) and every digit position is a power of ten. In base 2 you count with two symbols (0 and 1) and every position is a power of two. The same written number means different things in different bases, which is why 10 in binary is only worth two.

A handy rule of thumb: 2, 8 and 16 are all powers of two. That makes octal and hexadecimal natural shorthand for binary - three binary bits fit exactly into one octal digit, and four fit into one hex digit. The relationship is why these bases keep turning up together in computing.

The Four Bases at a Glance

  • Binary (base 2) - digits 0 and 1; the language of processor circuits.
  • Octal (base 8) - digits 0 to 7; classic shorthand for Unix permissions.
  • Decimal (base 10) - digits 0 to 9; everyday human counting.
  • Hexadecimal (base 16) - digits 0-9 and A-F; memory addresses, colours, encodings.

How the Invalid-Digit Check Works

Not every string is a valid number in every base. The converter examines each character you type against the selected source base: in binary only 0 and 1 are allowed, in octal anything from 0 to 7, and in hexadecimal the digits 0-9 together with the letters A-F. Type an 8 in a base-8 field and you get a clear, friendly error instead of a silently wrong answer.

Frequently Asked Questions

What is a radix (or base) in number systems?

The radix, or base, is the number of unique digits a counting system uses. Base 10 uses ten digits (0-9), base 2 uses two (0 and 1), base 8 uses eight (0-7) and base 16 uses sixteen (0-9 plus A-F). Each digit position represents that digit multiplied by a power of the radix, so the same symbols can describe very different values in different bases.

Can the converter work with bases beyond 16 such as base 32?

Not yet. This tool covers the four bases that matter most for everyday life and computing: 2, 8, 10 and 16. Bases beyond 16 need extra notational conventions for symbols after F, which is why they are left out of this converter for now.

Why are binary, octal, decimal and hexadecimal the most useful bases?

Binary is the only base computer hardware actually runs on, while octal and hexadecimal are compact shorthand for writing binary (one octal digit maps to three binary bits and one hex digit to four). Decimal is the base people use for everyday counting, so going between these two worlds covers almost every real conversion need.

Does the converter handle negative numbers?

Yes. Prefix the source value with a minus sign (for example -101 in binary) and the converter returns the negative value in the destination base as a minus sign followed by the positive magnitude. It does not interpret two's-complement notation, so a binary literal like -11 represents negative three, not an encoded bit pattern.
