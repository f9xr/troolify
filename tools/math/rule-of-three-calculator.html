Rule of Three Calculator: Solve Direct Proportion in Your Head (and Verify It Here)

Direct proportions show up constantly in daily life: if three apples cost two dollars, how much do seven cost? If a machine produces 120 parts in four hours, how many in nine? The rule of three gives you a simple formula to answer these questions, and this calculator does the algebra for you.

How the Rule of Three Works

When two ratios are equal - A is to B as C is to D - you can cross multiply: A × D = B × C. Rearranging for any one variable gives you the answer. Fill in three fields and leave the fourth blank; the calculator finds it instantly and shows the step-by-step working.

  • Solve for D: D = (B × C) ÷ A
  • Solve for C: C = (A × D) ÷ B
  • Solve for B: B = (A × D) ÷ C
  • Solve for A: A = (B × C) ÷ D

How to Use the Calculator

  1. Enter three values in any three of the four fields.
  2. Leave the unknown field blank - the calculator detects it and solves.
  3. Read the result in the statement line and see the working below.
  4. Copy the statement with one click for use in notes or assignments.

Frequently Asked Questions

What is the rule of three?

The rule of three is a method for solving direct proportion problems. If A is to B as C is to D, and you know any three of the four values, you can find the fourth using cross multiplication: D = (B × C) ÷ A (or the equivalent for whichever variable is unknown).

Which value can I leave blank?

You can leave any one of the four fields blank - A, B, C or D. The calculator detects which field is empty and solves for it using the other three values. All three known fields must contain non-zero numbers.

What if one value is zero?

The calculator requires three non-zero known values because the rule of three involves division. If the value you are solving for would require dividing by zero, the calculator shows an error message and explains why the calculation is not possible.

Is it the same as cross multiplication?

Yes. The rule of three is cross multiplication applied to a proportion. When A/B = C/D, cross multiplying gives A × D = B × C. Solving for any one variable is just rearranging that equation.
