IMEI Generator: Luhn-Valid Test IMEI Numbers on Demand

QA engineers, mobile developers and device registry administrators need valid IMEI numbers to test form validation, seed device databases and run automated tests on mobile enrollment flows. The Troolify IMEI Generator creates 15-digit Luhn-valid IMEI numbers with a choice of reporting body prefix, all generated locally in your browser.

What the IMEI Generator Does

The tool builds a 14-digit base number, optionally pinning the first 2 digits to reporting body 35, then appends the correct Luhn check digit as the 15th. The table splits every result into reporting body, TAC, serial and check digit columns so you can check the arithmetic yourself. You can generate up to 100 IMEIs at once and export them as Table, CSV, JSON or SQL INSERT statements. No data is uploaded anywhere.

How to Use the IMEI Generator

  1. Set the count - enter how many IMEI numbers to generate (1-100).
  2. Choose prefix style - Random, or RBI 35 to keep the reporting body at 35.
  3. Generate - click the Generate button.
  4. Choose export format - Table, CSV, JSON or SQL.
  5. Copy or download - grab the output instantly.

Frequently Asked Questions

What is an IMEI number?

An IMEI (International Mobile Equipment Identity) is a 15-digit identifier used to register mobile devices. The first 8 digits are the Type Allocation Code, the next 6 are the serial number and the 15th is a Luhn check digit.

Which prefix options are available?

Random draws any reporting body identifier. RBI 35 keeps the first 2 digits at 35, the allocation block used by many GSM devices. A TAC is not a manufacturer code, so neither option names a brand.

Are the generated IMEI numbers valid?

All of them pass the Luhn check, and the table breaks each number into reporting body, TAC, serial and check digit so you can verify the arithmetic. They are not registered to real devices.

Is my data safe?

Generation runs in your browser with JavaScript. Nothing is uploaded, logged or stored on a server.
