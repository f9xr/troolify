Cinder Block / CMU Wall Calculator

Concrete masonry unit (CMU) walls are measured in blocks, and underestimating block count stops a job dead. This calculator converts wall length and height into a block count for standard 16x8 inch CMU, adds a mortar bag estimate, and - if you plan to fill the cores - a grout volume for load-bearing or reinforced walls.

How to Use the Cinder Block / CMU Wall Calculator

  1. Measure the wall - length and height in feet.
  2. Choose the block - nominal 4, 6, 8 or 12 inch width.
  3. Toggle grouting - on for reinforced/load-bearing walls.
  4. Estimate - get block count, mortar bags and grout volume.

Why the Estimate Matters

Block count uses the standard 1.125 blocks per square foot rule, which accounts for the 3/8 inch mortar joint. Mortar is estimated at one 80 lb bag per 13 blocks, a conservative ceiling most masons use. Grouted walls add significant weight and material, so the optional core estimate keeps the number honest.

Contractor Tip

Order 5-10% extra blocks; waste on block walls runs higher than on slabs because of cuts at corners, openings and bond beams.

Frequently Asked Questions

How many blocks are in a square foot?

At the standard 16x8 inch size with a 3/8 inch joint, one block covers about 0.888 sq ft, so you need roughly 1.125 blocks per square foot of wall.

How much mortar do I need per block?

A common rule is one 80 lb bag of mortar mix for every 13 blocks - this calculator applies that rule and rounds up.
