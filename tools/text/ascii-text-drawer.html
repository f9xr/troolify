ASCII Text Drawer - Big Block Letter ASCII Art
Turn short text into big block-letter ASCII art, ready to paste into terminals and logs.
Block letters, old school
Before GUIs, terminals rendered banners with hashes and blocks. This drawer uses a classic 5x7 bitmap font - each glyph is seven rows of ## pairs - to turn short phrases into terminal-ready banners for README files, log headers or ASCII signatures.
How to use ASCII Text Drawer
  1. Type up to 14 characters (A-Z, 0-9, punctuation)
  2. Watch the banner render live
  3. Copy the art and paste it anywhere monospace text is welcome
Tips for getting accurate results
  • Keep phrases short - each character is 12 columns wide
  • Use the space character to separate words
  • The output uses only printable ASCII so it survives any text channel
Frequently asked questions
Which characters are supported?
A-Z, 0-9, space and common punctuation; lowercase is converted to uppercase.
Can I download it as a file?
Copy the art and save it as .txt - the clipboard copy preserves spacing.
