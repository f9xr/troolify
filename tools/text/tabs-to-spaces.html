Convert Tabs to Spaces: Keep Indentation Consistent

Few things torpedo a project faster than a tab-vs-spaces disagreement. Code that looks right in one editor can be a mess in another, and some languages refuse to compile or parse files that mix the two conventions.

About the Indentation Converter

In tabs to spaces mode, every tab character is expanded to the number of spaces you choose (4 by default), which gives your code the same indentation everywhere regardless of editor settings. In spaces to tabs mode, leading runs of exactly N spaces are collapsed into tab stops, and remaining runs of N are converted too - shrinking the file while keeping display alignment.

How to Use This Tool

  1. Paste your code or indented text into the box.
  2. Set spaces per tab to your team or language convention.
  3. Pick a direction - tabs to spaces, or the reverse.
  4. Copy the converted output back into your file.

Why Consistent Indentation Wins

Python's parser and YAML's spec are famously strict about indentation - a single tab where spaces are expected can raise a syntax error. Markdown nested lists and configuration files are just as sensitive. Because this converter runs entirely in the browser, you can normalize a proprietary or confidential file without uploading a byte of it. If you are cleaning up pasted configuration, the Space Remover and the Line Breaks Remover are handy companions.

Frequently Asked Questions

Why do Python and YAML care about tabs versus spaces?

Python treats a tab and four spaces as different indentation unless the file is consistently indented, and YAML refuses to allow tabs for indentation at all. Converting your source file to a single convention prevents these parser errors before you run the code.

What happens when I convert spaces back to tabs?

Leading runs of exactly N spaces are collapsed into tab stops, which matches how most editors display indentation. Any remaining space runs of exactly N are also converted, and you control N with the "Spaces per tab" setting.

Is the Troolify version safe for my data?
