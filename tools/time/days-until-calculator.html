Days Until Calculator: A Live Countdown to Any Date

Big dates are easier to plan when you can see exactly how much time is left. This days until calculator counts the days from today, or from any date you choose, to a target date, and breaks the gap into weeks, hours and a rough month figure.

Counting whole days

The tool compares two calendar dates and returns the number of whole days between them, ignoring the time of day so the answer stays stable. If you switch on count today, the current day is added to the total, which matches the common phrasing of sleeps until an event. For dates in the past it flips the wording to days ago, so the same tool works as a since counter.

What people count down to

Holidays, exam dates, product launches, wedding days, retirements and game releases are the usual subjects. Teachers count down to the end of term; project teams count working days to a go-live; and on a lighter note, streaming schedules and fan events are frequently tracked by the day.

How to use Days Until Calculator

  1. Enter the target date.
  2. Optionally set a different start date, otherwise today is used.
  3. Choose whether to count today.
  4. Press Count the days.

Tips for getting accurate results

  • Set a start date to count between two fixed dates instead of from today.
  • Turn on count today if you are counting sleeps until an event.
  • Use the hours figure for a finer sense of the time left.

Frequently asked questions

Does it include today?

Only if you switch count today on; by default the total is the number of whole days between the dates.

Can I count from a date other than today?

Yes. Set the from field and the count runs between your two chosen dates.

What happens with a past date?

The result is shown as days ago instead of days until.

Why do months show as approximate?

Months vary in length, so the month figure is a rough guide based on an average month.

Is my data private?

Yes. Everything is calculated locally in your browser.
