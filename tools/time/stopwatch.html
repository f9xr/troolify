Stopwatch: Precise Timing and Lap Recording in Your Browser

Sometimes you just need to time something quickly - a workout interval, a cooking step, a task to beat, a speech. This stopwatch gives you millisecond display, clean start and pause controls, and instant lap recording without any installs, trackers or accounts.

How It Works

Press Start to begin timing. The display updates about ten times per second with millisecond resolution. Press Pause to stop without losing your elapsed time, press Start again to resume, or press Reset to clear everything back to zero.

Split and Cumulative Times

Tap Lap at any moment to capture the current split. Each lap records the lap number, the split time (how long that lap took) and the cumulative total. New laps appear at the top of the list, and you can copy the entire summary to your clipboard for later use.

Built for Precision

Elapsed time is computed from a start timestamp, not by counting ticks. This matters because browsers can throttle background tabs; because the timer re-derives elapsed time from the clock on every refresh, it stays correct even if you switch tabs or lock the screen mid-timing.

Handy Use Cases

Use it for interval training or timed races, measuring the time it takes to complete a task, checking punctuality of processes, or timing a science experiment. It pairs naturally with the Countdown Timer for count-up versus count-down needs.

Frequently Asked Questions

How precise is the millisecond display?

Elapsed time is measured with JavaScript's millisecond timestamp, so the recorded value is millisecond-accurate to the best of the browser's clock resolution. The display refreshes about ten times per second for smooth reading; the underlying measurement itself is exact down to the millisecond.

What is a split vs cumulative time?

A split (or lap time) is how long the current lap took - the time since the previous lap marker. The cumulative time is the total elapsed time since the stopwatch started. The lap list shows both, newest lap first, so you can see each segment and the running total in one view.

Can I record unlimited laps?

Yes, there is no fixed limit - record as many laps as you need. Each lap is stored in the page's memory for the duration of your session, and you can copy the whole list to your clipboard at any time. A long list can be cleared with Reset when you are done.

Does it keep running if I switch tabs?

Yes. The stopwatch calculates elapsed time from a start timestamp rather than counting ticks, so it remains accurate even if the tab is throttled in the background. When the display refreshes again it shows the true elapsed time based on the clock, not on how many updates happened.

Conclusion

Whether you are timing a sprint, a task or an interval, this stopwatch provides accurate, private timing with lap recording and clipboard export - no account required.
