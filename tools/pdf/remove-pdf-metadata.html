Remove PDF Metadata: Share Clean Documents Without Hidden Traces

Before you email or publish a PDF, consider what it silently reveals. The document's metadata can name its author, the software that made it, and the dates it was created or edited - information you may not want shared. This tool scrubs those fields entirely in your browser.

About the Tool

By default the tool clears every standard info field. You can instead fill them with anonymous values ("Anonymous", default dates) if a recipient's software expects present-but-blank fields. The single most reliable option, enabled by default, is creating a fresh PDF by copying the pages - this rebuilds the file structure so hidden XMP packets are dropped alongside the info dictionary. Your content and layout are untouched.

How to Use This Tool

  1. Choose a PDF with the file picker.
  2. Keep "Clear ALL metadata fields" ticked, and keep fresh-copy mode on for the most complete strip.
  3. Optionally choose anonymous values instead of blank fields.
  4. Press Process PDF and download the cleaned file.

Why It Matters

PDFs are frequently shared with clients, reviewers and the public. A quick metadata sweep prevents accidental leakage of authorship and revision history, and the browser-based approach means the file itself never travels through an untrusted service while you clean it.

Frequently Asked Questions

Does removing metadata alter my PDF content?

No. Text, images and layout are untouched. The tool only clears the document's information fields - and in fresh-copy mode rebuilds the file structure so hidden XMP packets are dropped too.

Why should I create a fresh PDF copy?

Some producers embed metadata twice: once in the info dictionary and again as an XMP XML packet. Rebuilding the file by copying its pages is the only fully reliable client-side way to strip both, so it is the recommended option.

Is the Troolify version safe for my data?

Yes. Everything runs locally inside your browser tab - nothing you paste or upload is sent to a server, so drafts and data stay private.

Does it work on mobile?

Yes. Like all Troolify tools this runs on desktop and mobile browsers with no install and no account required.

Conclusion

With a single tool that clears all fields and offers true fresh-copy stripping, you can share your PDFs with confidence, knowing nothing hidden is going along for the ride - and nothing you do ever leaves your device.
