PDF Metadata Viewer: See What's Hidden Inside Your Documents

Every PDF can carry a hidden layer of information - the title, author, the application that produced it, and the exact dates it was created and modified. This viewer surfaces all of that locally, so you know what your file says about itself before you share it.

About the Tool

The viewer reads the document's info dictionary with the PDF.js engine and also reconstructs the raw field values into readable JSON. Fields that the file does not define are shown as an em dash so you always know whether a value is genuinely present or simply absent.

How to Use This Tool

  1. Choose a PDF with the file picker.
  2. Press Read Metadata - all fields appear instantly.
  3. Review the raw dictionary in the JSON box for exact stored values.

Why It Matters

Before distributing a document, professionals check its metadata - it can reveal authorship, the software used, and revision dates that you might not want public. Seeing that information here, privately, lets you decide whether to clean it with our companion Remove PDF Metadata tool.

Frequently Asked Questions

What metadata does a PDF contain?

Most PDFs embed a document info dictionary holding title, author, subject, keywords, creator, producer, and created/modified dates. Modern files may also carry an XMP metadata packet with more detail.

Where is PDF metadata stored?

Metadata lives inside the file itself, in the document information dictionary referenced from the catalog trailer, and often duplicated as XMP XML. It is not stored on any server - which is why this viewer reads it locally.

Is the Troolify version safe for my data?

Yes. Everything runs locally inside your browser tab - nothing you paste or upload is sent to a server, so drafts and data stay private.

Does it work on mobile?

Yes. Like all Troolify tools this runs on desktop and mobile browsers with no install and no account required.

Conclusion

Metadata tells a story about every PDF, and knowing that story is the first step to controlling it. Inspect any file in seconds - privately, for free, right in your browser. Once you know what is stored, use our Remove PDF Metadata tool to strip it before sharing.
