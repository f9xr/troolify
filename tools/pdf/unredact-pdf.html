Unredact a PDF: Recover Text That Was Only Covered, Not Removed

Redaction is supposed to permanently remove text, but many people "edit" PDFs by drawing a solid black rectangle over the words. Those characters stay hidden in the file. This tool reads the full content stream and surfaces that text, letting you recover words that are still physically present.

About the Tool

The PDF.js engine extracts every text item in the document's content stream - including text that sits underneath opaque shapes. If a black-out rectangle was simply drawn on top, the underlying text is still there, and this tool finds it and arranges it back into readable order page by page.

How to Use This Tool

  1. Choose the PDF with the file picker.
  2. Press Extract hidden text to scan every page.
  3. Review the output and copy or download it as a .txt file.

Important Limits (Read This)

This only works when the original text still exists in the file - the common case of black-box or highlight "editing". It CANNOT recover text from a PDF that was properly redacted (where the characters were physically removed or the page flattened), nor from encrypted or scanned PDFs. Always check whether the result is complete before relying on it.

Frequently Asked Questions

When can this tool recover redacted text?

Only when the original text is still physically present in the file - which happens when someone covered it with a black rectangle, highlight, or opaque shape instead of truly removing it. If the text was genuinely removed or flattened, it cannot be recovered.

Is it possible to recover text from a properly redacted PDF?

No. When a PDF is redacted correctly, the underlying characters are physically deleted from the content stream and are gone forever. Likewise, encrypted or scanned PDFs have no recoverable text layer. This tool cannot undo those cases.

Is the Troolify version safe for my data?

Yes. Everything runs locally inside your browser tab - nothing you paste or upload is sent to a server, so drafts and data stay private.

Does it work on mobile?

Yes. Like all Troolify tools this runs on desktop and mobile browsers with no install and no account required.

Conclusion

If you have a PDF where text was hidden behind a drawn box rather than truly removed, this tool can bring it back - quickly, privately and honestly about its limits. It is a practical recovery aid for your own documents, not a magic bullet for genuine redaction. For regular text extraction from unredacted PDFs, use the PDF to Text tool.
