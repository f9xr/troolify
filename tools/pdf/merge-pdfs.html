Merge PDFs into One: Combine Documents in Any Order

When you need to deliver several PDF files as a single package, merging them into one document is the cleanest solution. This browser-based tool lets you combine any number of PDFs, reorder them, and optionally add bookmarks — all without uploading a single file.

About the Tool

The tool uses pdf-lib to load each source PDF and copy its pages into a new document, preserving page content and dimensions. You can reorder the files up and down in the list, and remove any you no longer need. When the bookmarks option is enabled, a PDF outline item is created for each source document, pointing to its first page for easy navigation.

If a file cannot be read as a valid PDF, it is skipped and a warning is shown, while the remaining files are still merged successfully.

How to Use This Tool

  1. Select PDF files — choose one or more PDFs from your device.
  2. Arrange the order — use the up/down arrows and remove buttons in the list.
  3. Optionally enable bookmarks — for easy navigation between source documents.
  4. Click Merge — all pages are combined into one PDF.
  5. Download — save the merged document to your device.

Why It Matters

Merging PDFs is a routine need for submitting applications, bundling reports, combining scanned documents, and assembling e-books. Doing it in your browser keeps sensitive content private and avoids the file-size and upload limits of many online services.

Frequently Asked Questions

Can I reorder the files before merging?

Yes. Each file in the list has up, down, and remove buttons so you can arrange them in any order before merging. The output follows the order shown in the list.

What does 'add bookmarks per source document' do?

When enabled, the merged PDF gets a bookmark (outline item) for each source file, pointing to the first page of that file. This makes navigation much easier when combining many documents into one large PDF.

Is there a limit on the number of files I can merge?

There is no hard limit. You can select many PDFs at once and they are added to the list. Keep total size under 100 MB for best browser performance.

Are corrupt or invalid files a problem?

If a file cannot be parsed as a valid PDF, the tool skips it and shows a warning while continuing to merge the remaining files. Your other documents are not affected.
