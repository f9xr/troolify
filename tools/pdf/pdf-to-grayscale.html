PDF to Grayscale: Remove Color from Any PDF

Whether you need a black-and-white version of a document for printing, archiving, or compliance, this browser-based tool converts colored PDFs to grayscale without uploading anything. Each page is rendered as an image, desaturated, and assembled into a new PDF.

About the Tool

The tool uses pdf.js to render each page of your PDF onto an off-screen canvas at the chosen scale (1.0x, 1.5x, or 2.0x). The pixel data is then processed: the RGB channels are averaged to produce a luminance value, replacing the original colors with grayscale. The desaturated image is compressed as a JPEG and embedded into a fresh pdf-lib PDF page.

Higher render scales produce sharper output at the cost of larger file sizes. At 1.0x, a standard letter page renders at roughly 612x792 pixels; at 2.0x, it doubles to 1224x1584 pixels for print-quality sharpness.

How to Use This Tool

  1. Upload your PDF — choose any PDF file from your device.
  2. Choose render quality — 1.0x for smaller files, 2.0x for sharpest output.
  3. Click Convert — each page is rendered and desaturated in your browser.
  4. Download — save the grayscale PDF to your device.

Honest Limitations

The output is image-based. Each page becomes a raster image embedded in the PDF, which means selectable text and hyperlinks are lost. The "Keep original text layer" option attempts to overlay the original text for selectability, but alignment may vary depending on fonts and layout. For vector-level grayscale conversion, desktop tools like Adobe Acrobat are recommended.

Very large PDFs (100+ pages) may take longer to process as each page must be rendered individually in the browser.

Why It Matters

Grayscale conversion is common for printing cost reduction, academic submission requirements, accessibility, and archiving. Doing it in the browser means confidential documents stay on your device, and you avoid the friction of installing desktop software for a simple task.

Frequently Asked Questions

Will I lose text and links in the converted PDF?

Yes, partially. The tool renders each page as an image and embeds it into a new PDF. This flattens text into pixels, so the output pages are images. Selectable text, bookmarks, and hyperlinks from the original are lost. If you need to preserve text, you would need to use a desktop tool with vector-level grayscale support.

What does the render scale option do?

The render scale controls how many pixels per PDF point are used when rasterizing each page. Higher values (1.5 or 2.0) produce sharper output at the cost of larger file sizes. Use 1.0 for smaller files, 2.0 for print-quality sharpness.

Is there a page limit?

There is no hard limit, but large multi-page PDFs consume significant browser memory. For documents over 100 pages, processing may be slow. Keep total file size under 50 MB for best results.

Does it work on mobile?

Yes. Like all Troolify tools this runs on desktop and mobile browsers with no install and no account required.

Conclusion

For quick, private conversion of colored PDFs to black and white, this tool provides a straightforward path. The output is image-based, making it reliable for printing and sharing. For more complex editing, pair it with the Merge PDFs tool to combine the result with other documents.
