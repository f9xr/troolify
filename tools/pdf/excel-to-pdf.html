Convert Excel to PDF: Print-Ready Spreadsheets in One Click

Converting a spreadsheet to PDF should not require emailing a file to a third-party service. This browser-based tool reads your Excel file, renders the selected sheet as a bordered table, and generates a downloadable PDF entirely on your machine.

About the Tool

The tool uses the SheetJS library to parse .xlsx, .xls, and .csv files. Once a sheet is selected, its rows are read as a 2D array. Each column's width is estimated by the longest text value (capped at 30 characters), and the table is drawn onto a pdf-lib PDF page using Helvetica 8pt font with simple border lines between cells. The header row is drawn in bold.

You can toggle between Portrait and Landscape orientation before converting, which is useful for spreadsheets with many columns.

How to Use This Tool

  1. Upload your file — choose an .xlsx, .xls, or .csv file.
  2. Pick a sheet — if the workbook has multiple sheets, a dropdown will appear.
  3. Choose orientation — Portrait for narrow tables, Landscape for wide ones.
  4. Click Convert — the PDF renders in your browser.
  5. Download — save the generated PDF to your device.

Honest Limitations

The tool renders cell values as a simple table. Formulas are evaluated to their displayed values by SheetJS, but charts, images, conditional formatting, merged cells, and cell styling (colors, borders beyond basic lines) are not preserved. For pixel-perfect conversion, use Microsoft Excel's native Export to PDF or LibreOffice Calc.

Why It Matters

Quick sharing of spreadsheet data in PDF format is common in business, education, and personal workflows. This tool provides a zero-install, zero-upload path to a print-ready PDF, keeping confidential financial data and personal records entirely on your device.

Frequently Asked Questions

What Excel formats are supported?

The tool supports .xlsx, .xls, and .csv files. All parsing happens in your browser using the SheetJS library.

Will formulas and charts be included in the PDF?

No. The tool renders the calculated values of cells as a table in the PDF. Formulas, charts, conditional formatting, and images from the spreadsheet are not included. For full-fidelity conversion, use Microsoft Excel's built-in Export to PDF.

Can I choose portrait or landscape orientation?

Yes. A radio toggle lets you pick Portrait (612x792) or Landscape (792x612) before conversion. Choose landscape for wide spreadsheets with many columns.

Does it work on mobile?

Yes. Like all Troolify tools this runs on desktop and mobile browsers with no install and no account required.

Conclusion

For quick, private conversion of spreadsheets to printable PDFs, this tool covers the most common use cases without any file upload. Pair it with the Merge PDFs tool to combine multiple converted sheets into a single document.
