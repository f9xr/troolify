BPM to Delay Time Calculator: Lock Your Echoes to the Tempo

A delay that drifts a few milliseconds off the beat instantly turns a tight mix into a muddy smear. Producers fix this not by guessing, but by setting the delay time for a musical note value of the track's tempo. This BPM to delay time calculator does exactly that, returning note-accurate millisecond times in your browser in a fraction of a second.

How to Use the BPM to Delay Time Calculator

  1. Enter your track's tempo in beats per minute, or tap a preset button for a common genre tempo.
  2. Pick a reference note - usually a quarter note (one beat) or an eighth note.
  3. Read the table: each row shows the straight value, the +dotted (×1.5) value and the −triplet (×0.667) value in milliseconds.
  4. Type each value into your delay or reverb and listen - the echoes now land exactly on subdivisions of the beat.

At 120 BPM, the quarter note is exactly 500 ms. Everything else scales from there: a dotted eighth is 375 ms, and an eighth-note triplet is about 167 ms.

The Delay Time Formula

The math behind the whole calculator is a single line: beat duration in ms = 60000 / BPM. The reference note value is then divided by the note ratio, so a quarter note (ratio 1) at 120 BPM gives 60000 / 120 / 1 = 500 ms.

  • Straight note times: divide the beat by the note fraction (whole = 0.25, half = 0.5, quarter = 1, eighth = 2, sixteenth = 4).
  • +Dotted times multiply the straight value by 1.5, giving the classic reggae-style and dub traces.
  • −Triplet times multiply by two-thirds, giving a galloping, off-grid ripple.

Common Delay Styles at a Glance

The dotted-eighth delay is the go-to for reggae, dub and many pop vocals because it bounces against the straight groove. Straight quarter-note delays feel wide and half-time, ideal for minimal Techno. Triplet delays shine on open-sounding intros and electronic breakdowns where an unpredictable ripple carries the track.

Frequently Asked Questions

How do I calculate delay time from BPM?

Start from the beat duration: one beat lasts 60000 / BPM milliseconds. At 120 BPM a quarter note (one beat) is exactly 500 ms. Scale by the note ratio for other values - a half note is 1000 ms, an eighth note is 250 ms, and so on.

What is a dotted delay time?

A dotted note lasts 1.5 times longer than its straight equivalent. A dotted eighth is a favourite for reggae and dub style echoes because it answers every second beat against the straight groove.

What is a triplet delay time?

A triplet squeezes three subdivisions into the space of two, so the triplet value is about 0.667 of the straight note length. Triplet echoes add a syncopated, galloping feel that avoids the simple beat grid.
