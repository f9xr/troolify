Htaccess Redirect Generator: Move URLs Safely

Redirecting old URLs preserves traffic and link equity. This htaccess redirect generator builds Apache rewrite rules from your old and new paths.

Choosing a status code

Use 301 for permanent moves so search engines transfer signals. Use 302 or 307 for temporary changes that should not be cached.

Apache requirement

These rules need mod_rewrite enabled. Place them in the site .htaccess file or the virtual host configuration.

How to use Htaccess Redirect Generator

  1. List old and new paths.
  2. Pick the status code.
  3. Paste the rules into .htaccess.
