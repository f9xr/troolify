LLMs.txt Generator: Guide AI Crawlers

llms.txt is a growing convention that summarises a site for AI language models. This llms.txt generator builds a clean Markdown file with your key pages.

What llms.txt is

It is a Markdown file at your site root that names the site, gives a short summary and links important pages, giving AI tools a curated starting point.

Adoption caveat

Support varies between AI providers. Publishing it is low-cost and future-friendly, but do not expect universal recognition yet.

How to use LLMs.txt Generator

  1. Enter site name, URL and summary.
  2. List key pages and links.
  3. Copy the file to your site root.
