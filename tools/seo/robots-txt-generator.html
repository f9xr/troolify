Robots.txt Generator: Control Crawler Access

Robots.txt tells search engine crawlers which paths to avoid. This robots.txt generator builds a valid file with rules, a crawl delay and a sitemap reference.

How rules work

Each block starts with a User-agent and lists Disallow paths. An empty Disallow allows everything; a Disallow of / blocks the whole site.

Good to know

Robots.txt is a request, not enforcement, and is not a security measure. Never rely on it to hide private pages - use authentication instead.

How to use Robots.txt Generator

  1. Set the user-agent and any disallow paths.
  2. Optionally add a sitemap and crawl delay.
  3. Copy the file to your site root.
