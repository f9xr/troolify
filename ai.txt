## Key Features
- Free forever, no sign-up required
- 100% client-side processing, zero data retention
- Privacy-first architecture - no server uploads
- 70+ tools across 20 categories
- Responsive design, works on all devices

## Tools by Category
- **Text Tools**: Word counter, numeronym generator, random word generator
- **Developer Tools**: JSON formatter, code beautifier, URL encoder/decoder, CSV to JSON, SHA hash generator
- **SEO Tools**: Schema markup generator, multiline slug generator
- **Audio Tools**: Song length calculator, BPM tools
- **Health Tools**: Ovulation calculator, macro calculator, TDEE calculator, body fat percentage, pregnancy due date
- **HVAC Tools**: Load calculators, duct sizing, refrigeration tools, psychrometric calculator
- **Finance Tools**: VAT calculator
- **Image Tools**: Color converter
- **Converters**: Markdown to Word/PDF
- **Password Tools**: Password generator, entropy calculator

## Technical Details
- Built with: HTML5, vanilla JavaScript, Tailwind CSS
- Hosting: GitHub Pages
- No backend required
- No user accounts or tracking
- All processing happens in the browser
