# Troolify - AI Agent Information

> Free, privacy-first online tools hub. Most tools run 100% client-side in the browser - a few are clearly labelled API-powered tools.

## Site Overview
- **Name**: Troolify
- **Type**: Static website with client-side tools
- **URL**: https://f9xr.org/troolify/
- **Repository**: https://github.com/f9xr/troolify
- **Team**: F9XR Team
- **Contact**: hello@f9xr.org

## Key Features
- Free forever, no sign-up required
- Processing is client-side with zero data retention (a few labelled tools call a public API)
- Privacy-first architecture - no server uploads
- 300+ tools across 25 categories
- A few optional tools are powered by a public web API (abhi-api.vercel.app) and always labelled on-page - the rest stay 100% client-side
- Responsive design, works on all devices

## Technical Details
- Built with: HTML5, vanilla JavaScript, Tailwind CSS
- Hosting: GitHub Pages
- No backend required
- No user accounts or tracking
- Nearly all processing happens in the browser (a few labelled tools call a public API)
